# 프로필: GamePix

## 1단계 점검
- 모든 src/*.js 문법 통과 (node --check)
- 실행 중 콘솔 오류 0건
- 외부 통신 0건
- 자동 플레이가 시작부터 사망까지 진행
- localStorage가 막힌 환경에서 실행
- zip 한 개로 실행 (dist/)
- 게임성 수치: 무작위 대 2수 읽기 도달 차이, 빌드별 차이 (목표는 GOAL.md)
- 미확인: 광고 SDK 연동이 필수인지 (https://docs.gamepix.com/docs 확인 필요)

## 2단계 화면
- 크기: 390x844(세로), 1280x720(가로)
- 장면: 첫 화면 / 시작 10초 뒤 / 전투 순간 / 선택 화면 / 사망 화면 / 썸네일 크기 축소본
- 연속 장면: 공격 한 번 6장
